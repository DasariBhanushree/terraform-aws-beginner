# Terraform AWS Infrastructure Automation Project

## Project Overview
Built AWS infrastructure using Terraform and automated Docker installation on EC2 using user_data.

## Architecture
Terraform
→ Custom VPC
→ Public Subnet
→ Route Table
→ Internet Gateway
→ Security Group
→ EC2
→ Docker
→ Nginx Container
→ Public Website Access

## Technologies Used
- Terraform
- AWS EC2
- AWS VPC
- Docker
- Linux
- GitHub Codespaces
- Git & GitHub

## Features
- Automated EC2 provisioning
- Custom VPC creation
- Public subnet configuration
- Security Group automation
- SSH key automation
- Docker auto-installation using user_data
- Nginx container deployment
- Public website hosting
